# chat-with-docs

Upload PDFs, ask questions, and get answers that cite the exact page they came from. It includes user accounts, separate workspaces, and an **evaluation page that measures how accurate the answers really are**.

## Tech stack

- **Python:** fastapi, uvicorn, sqlalchemy, pydantic-settings, email-validator, python-multipart, pyjwt, bcrypt, pypdf, chromadb, sentence-transformers, openai

## Quick start

1. Get the code:

   ```bash
   git clone https://github.com/gideonswer/chat-with-docs.git
   cd chat-with-docs
   ```

2. Install the dependencies in a virtual environment:

   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate   macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Create your settings file, then fill in your values:

   ```bash
   cp .env.example .env
   ```

4. Start it:

   ```bash
   uvicorn app.main:app --reload
   ```
